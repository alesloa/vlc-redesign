# Inter

The owner's Figma reference uses Inter Regular, Medium and SemiBold. These
unmodified TrueType files are from the typeface author's Inter 4.1 release:
https://github.com/rsms/inter/releases/tag/v4.1

The SIL Open Font License is included in LICENSE.txt. Qt and AppKit register
these files for the VLC process; installation into the operating system is not
required.

## Behavior and data sources

Media titles, covers, counts, timestamps, stream URLs, devices, tracks, chapters and bookmarks come from VLC's existing models and configuration descriptors. Figma example media are not seeded into VLC. User pins and user-selected playlist cover images are GUI presentation preferences; they refer to actual media-library IDs and local files.

The walkthrough also proposes additional player capabilities. The existing code determines which can be implemented at the GUI boundary:

| Capability | Existing source/API | GUI decision |
| --- | --- | --- |
| Decoded seek preview | Public `vlc_preparser_req_NewThumbnail` / thumbnail-to-files preparser API | Qt and native GUI adapters use actual frame requests with time-only fallback; Qt frame/cache/destruction/cancellation/hover/time and unchanged-position checks passed; native real frame/252×142 image/272×189 panel and twelve request/cancel cycles passed |
| Subtitle cue timeline | Current Qt/player/preparser exposes tracks and synchronization, no decoded cue text/time list | Omitted; requires a new core data interface |
| Seekbar audio waveform | Current Qt/player/preparser exposes no decoded peak sample array | Omitted; existing Audio Visualization choices remain available |
| Automatic local track association | Existing media-library filename/sidecar association | Preserved; manual external-track mappings use existing stored subtitle/soundtrack files and GUI input conversion |
| Reverse playback | Existing rewindable/rate capability | Existing rewind capability determines availability; no synthetic reverse decoder |
| Sleep timer | Existing playlist Stop action | GUI monotonic timer accepts the user's duration; actual validation/Cancel/expiry/original Stop passed in Qt and native macOS |
| Per-show presets | Existing Shows/episode membership queries, typed GUI option models, live sync properties and GUI settings | User-named Subtitle/Audio/Video snapshots use actual show membership or actual local parent-folder scope. Qt typed capture/Save/JSON reload/scoped visibility/Apply/source restore/Delete passed; native all three sections passed staged Save/Cancel, same-profile restart, Apply/live restoration and Delete with real folder scope. Show-membership queries are implemented, but an actual TV-episode fixture was not exercised |
| Global setting profiles | Existing configuration descriptors and GUI settings | User-named explicit review workflow implemented. Final Qt New/Save/Apply/Delete/Cancel, independent Light/Dark, opacity and unknown-provider preservation passed; 1,053 browsable typed options round-trip exactly and hidden launch options remain untouched. Native actual staged Cancel/Save/Apply/Delete and shared-schema preservation passed, including the real Windows-only `d3d11-upscale-mode` record |

A presentation-only redesign must not substitute inert controls for unavailable behavior or silently change VLC's core.
